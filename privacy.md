# Privacy Policy

Calendar MCP Server is a personal tool used only by its owner.

- It accesses only the owner's own Google Calendar, through the Google Calendar API, with the owner's consent.
- Calendar data is processed locally on the owner's machine and is not sold, shared with or transferred to third parties.
- OAuth tokens are stored locally and can be revoked at any time at https://myaccount.google.com/permissions.

The use of information received from Google APIs adheres to the [Google API Services User Data Policy](https://developers.google.com/terms/api-services-user-data-policy), including the Limited Use requirements.
